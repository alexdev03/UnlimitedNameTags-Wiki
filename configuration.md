# Configuration (`settings.yml`)

The primary configuration of **UnlimitedNameTags** is managed within
`plugins/UnlimitedNameTags/settings.yml`. This file is automatically generated on the first
server startup. After modifying the configuration, execute the command `/unt reload` to apply
your changes.

For optional, advanced helmet-height offsets, refer to the [advanced.yml Guide](features/advanced-yml.md).

---

## Configuration Structure

The `settings.yml` file is structured into three distinct layers:

1. **Global Settings**: Located under the `behavior`, `visibility`, and `performance` sections.
   These options define general timing, formatting, client render distances, and performance
   optimizations.
1. **Name Tag Presets (`nameTags`)**: Named configurations (e.g., `default`, `vip`) assigned
   to players. The plugin evaluates presets top-to-bottom, assigning the first preset for
   which a player holds the required permission. If no specific permission matches, the fallback
   `default` preset is applied.
1. **Placeholder Replacements (`placeholdersReplacements`)**: Custom rules designed to format or
   clean raw PlaceholderAPI returns before they render on name tags.

Each name tag preset contains one or more **`displayGroups`**, which represent the stacked layout
rows (comprising text lines, items, or blocks) rendered above the player's head. The stack is
ordered from top to bottom as written in the configuration.

---

### Understanding Time Units: "Ticks"

Time-based values within the configuration are defined in **ticks**. 
- In a standard Minecraft server environment, **20 ticks correspond to 1 second**.
- For example, setting `taskInterval: 20` instructs the plugin to update placeholders approximately
  once per second.

---

## Complete Example (`configVersion: 5`)

Below is a reference `settings.yml` configuration demonstrating a two-preset setup and a placeholder replacement rule:

```yaml
configVersion: 5

behavior:
  taskInterval: 20
  displayAnimationInterval: 1
  yOffset: 0.3
  viewDistance: 60
  compactDisplayGroupStack: false
  displayGroupLineHeightBlocks: 0.25
  disableDefaultNameTag: true
  forceDisableDefaultNameTag: false
  defaultBillboard: CENTER
  format: MINIMESSAGE
  removeEmptyLines: true

visibility:
  sneakOpacity: 70
  showWhileLooking: false
  showCurrentNameTag: false
  allowPerPlayerShowOwnWhenGlobalDisabled: false
  throughWallMode: SEE_THROUGH
  throughWallSettings:
    opacity: 55
    maxDistance: 48.0
    checkInterval: 5

performance:
  componentCaching: false
  placeholderCacheTime: 1
  enableRelationalPlaceholders: false
  placeholderUpdateRates: {}

nameTags:
  vip:
    permission: 'group.vip'
    displayGroups:
      - lines:
          - text: '<gold>%player_name%</gold>'
          - text: '<green>Rich</green>'
            when: '%vault_eco_balance% > 1000'
        background:
          enabled: true
          color: '#1a1a1a'
          opacity: 200
          shadowed: false
          seeThrough: false
        scale: 1.1
        yOffset: 0.0
  default:
    displayGroups:
      - lines:
          - text: '%luckperms_prefix%%player_name%%luckperms_suffix%'
        scale: 1.0
        yOffset: 0.0

placeholdersReplacements:
  '%advancedvanish_is_vanished%':
    - placeholder: "Yes"
      replacement: ' &7[V]&r'
    - placeholder: "No"
      replacement: ''
```

## Global Options

### `behavior` Section

| Option | Default | Description |
| :--- | :--- | :--- |
| **`taskInterval`** | `20` | Ticks between placeholder refreshes. Increasing this value reduces CPU usage but slows down text updates. |
| **`displayAnimationInterval`** | `1` | Ticks between animation frames or position updates. Set to `0` to inherit `taskInterval`. |
| **`yOffset`** | `0.3` | Vertical offset (in blocks) applied to the entire name tag stack. |
| **`viewDistance`** | `60` | Client-side render distance suggestion. Lower values prevent tags from rendering at long distances. |
| **`compactDisplayGroupStack`** | `false` | If enabled (`true`), empty or hidden display rows will not reserve blank space in the stack layout. |
| **`displayGroupLineHeightBlocks`** | `0.25` | Estimated height (in blocks) of a text line, used when calculating compact layout heights. |
| **`disableDefaultNameTag`** | `true` | Disables the vanilla name tag rendering to prevent visual overlap. |
| **`forceDisableDefaultNameTag`** | `false` | Enforces team cache visibility rules. Useful if custom NPCs share a real player's username. |
| **`defaultBillboard`** | `CENTER` | Camera-alignment behavior. Options: `CENTER`, `HORIZONTAL`, `VERTICAL`, `FIXED`. (See [Billboard Settings](features/billboards.md)). |
| **`format`** | `MINIMESSAGE` | Formatting engine for colors and decorations. Supported: `MINIMESSAGE`, `LEGACY` (`&`), `UNIVERSAL` (both), `MINEDOWN`. |
| **`removeEmptyLines`** | `true` | Automatically hides lines where placeholders resolve to an empty string. |

### `visibility` Section

| Option | Default | Description |
| :--- | :--- | :--- |
| **`sneakOpacity`** | `70` | Translucency value (0–127) when a player sneaks. Set to `-1` for full opacity. |
| **`showWhileLooking`** | `false` | If enabled, the tag is only rendered when the viewer looks directly at the player. (See [Show While Looking](features/show-while-looking.md)). |
| **`showCurrentNameTag`** | `false` | Allows players to see their own name tags. Requires the permission node `unt.showownnametag`. |
| **`allowPerPlayerShowOwnWhenGlobalDisabled`** | `false` | Allows players to toggle their own name tag visibility via `/unt preferences showown` even if `showCurrentNameTag` is set to `false`. |
| **`throughWallMode`** | `SEE_THROUGH` | Direct line-of-sight visibility mode. Options: `SEE_THROUGH` (vanilla), `OBSCURED` (dims tag behind walls), `HIDE` (completely hides tag behind walls, anti-wallhack). |
| **`throughWallSettings.opacity`** | `55` | Translucency value (0–127) applied when the player's tag is obstructed in `OBSCURED` mode. |
| **`throughWallSettings.maxDistance`** | `48.0` | Maximum distance (in blocks) for line-of-sight obstruction checks. |
| **`throughWallSettings.checkInterval`** | `5` | Ticks between line-of-sight checks. This check runs synchronously; increase this value on large servers to reduce load. |

### `performance` Section

| Option | Default | Description |
| :--- | :--- | :--- |
| **`componentCaching`** | `false` | Caches formatted components to reduce text parsing overhead. Can cause delayed text updates or conflict with MiniPlaceholders. |
| **`placeholderCacheTime`** | `1` | Default caching duration (in ticks) for individual placeholders. |
| **`enableRelationalPlaceholders`** | `false` | Evaluates PlaceholderAPI variables on a per-viewer basis. Required for relational placeholders, but incurs a performance cost. |
| **`placeholderUpdateRates`** | `{}` | Key-value mapping to define specific update rates per placeholder. E.g., `'%vault_eco_balance%': 100`. |

## `nameTags` Presets

Each entry under `nameTags` defines a specific layout. The plugin parses these presets sequentially
from top to bottom, checking if the player possesses the defined permission.

```yaml
nameTags:
  staff:                       # Custom preset key
    permission: 'group.staff'  # Target permission node
    displayGroups:
      - ...
```

> [!IMPORTANT]
> The `default` preset (which lacks a `permission:` key) acts as the fallback. It should always be
> placed at the very bottom of the `nameTags` list to capture players who do not match any prior
> permission.

## Display Group Fields Reference

| Option | Default | Description |
| :--- | :--- | :--- |
| **`lines`** | `[]` | List of text objects for a `TEXT` display row. Each item uses the format `{text: '...', when: '...'}`. Ignored on item/block displays. |
| **`background`** | `null` | Custom background configuration. Refer to the Background sub-section below. |
| **`scale`** | `1.0` | Scale multiplier for the group. |
| **`yOffset`** | `0.0` | Vertical offset (in blocks) from the base group stack. |
| **`when`** | `null` | A logical condition string. If evaluated to false, the entire display group is hidden. Supports Placeholders. |
| **`relationalConditions`** | `false` | Evaluates the `when` condition per-viewer. Automatically enabled if `%rel_` or `%relational_` is detected in the condition. |
| **`displayType`** | `TEXT` | Entity format: `TEXT`, `ITEM`, or `BLOCK`. (See [Display Groups](features/display-groups.md)). |
| **`itemMaterial`** | `STONE` | Block/item type to display if `displayType` is set to `ITEM`. Supports Placeholders. |
| **`blockMaterial`** | `STONE` | Block type to display if `displayType` is set to `BLOCK`. Supports Placeholders. |
| **`itemDisplayMode`** | `null` | Display orientation for items (e.g., `HEAD`, `GROUND`, `FIXED`, `THIRDPERSON_LEFTHAND`). |
| **`animation`** | `null` | Animation preset ID to apply. (See [Animations](features/animations.md)). |
| **`animationInterval`** | `null` | Overrides `displayAnimationInterval` for this specific display group. |
| **`billboard`** | `null` | Overrides the default camera-facing billboard mode for this specific group. |

### Background Setup

To configure a colored background plate behind your text lines, use the following layout:

```yaml
background:
  enabled: true
  color: '#1a1a1a'    # Hex code or RGB triplet ('26,26,26')
  opacity: 200        # Alpha channel (0 to 255)
  shadowed: false
  seeThrough: false
```

| Field | Description |
| :--- | :--- |
| **`enabled`** | Enables or disables the rendering of the background plate. |
| **`color`** | Color defined as a hex string (`'#RRGGBB'`) or RGB format (`'R,G,B'`). |
| **`opacity`** | Transparency control. `0` represents fully transparent, while `255` is fully opaque. |
| **`shadowed`** | Enables a default text drop-shadow effect. |
| **`seeThrough`** | Renders the text through opaque block geometry when the group entity is visible. |

### Per-Line Visibility Conditions

In configuration schema version 4, the `lines` field contains a list of objects, allowing you to
hide or show individual text lines using conditions:

```yaml
lines:
  - text: '%player_name%'
  - text: '<green>%player_ping%ms</green>'
    when: '%player_ping% < 70'
  - text: '<red>%player_ping%ms</red>'
    when: '%player_ping% >= 70'
```

- **Line-level `when`**: Evaluated to show or hide a single line.
- **Group-level `when`**: Hides or shows the entire row entity. The group-level check is evaluated
  first; if it returns false, line conditions are skipped entirely.

## `placeholdersReplacements`

You can define rules to map raw outputs of PlaceholderAPI placeholders to custom text strings or
styles:

```yaml
placeholdersReplacements:
  '%advancedvanish_is_vanished%':
    - placeholder: "Yes"
      replacement: ' &7[V]&r'
    - placeholder: "No"
      replacement: ''
```

> [!WARNING]
> The YAML 1.1 specification interprets unquoted keywords such as `Yes`, `No`, `On`, `Off`, `True`,
> and `False` as booleans. To prevent parsing errors, **always enclose keys or values matching
> these terms in quotation marks** (e.g., `"Yes"`, `"No"`).

For advanced configurations, see the [Placeholder Replacements Guide](features/placeholders-replacements.md).
