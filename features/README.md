# Features

Explore the core features and customization options of **UnlimitedNameTags**:

- **[Display Groups](display-groups.md)**: Stack lines, define visibility conditions, and render
  text, items, or blocks above player heads.
- **[Animations](animations.md)**: Text phase placeholders and physical motion on display rows.
- **[Billboard Settings](billboards.md)**: Control how display groups orient themselves relative to
  the viewer's camera.
- **[Placeholder Replacements](placeholders-replacements.md)**: Map and format raw text output
  from PlaceholderAPI variables.
- **[Formatters](formatters.md)**: MiniMessage, Legacy, Universal, and MineDown parsing.
- **[Show While Looking](show-while-looking.md)**: Crosshair targeting and through-wall modes
  (`SEE_THROUGH`, `OBSCURED`, `HIDE`).
- **[Sneak & Own Nametag](sneak-and-own-nametag.md)**: Sneak opacity and seeing your own tag.
- **[Player Preferences](player-preferences.md)**: Per-player visibility toggles via `/unt preferences`.
- **[Glow](glow.md)**: Colored outline glow on text, item, and block display rows.
- **[Advanced Configuration](advanced-yml.md)**: Custom helmet height offsets in `advanced.yml`.

To optimize these features for larger servers, refer to the [Performance Tuning Guide](../performance.md).
