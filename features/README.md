# Features

Explore the core features and customization options of **UnlimitedNameTags**:

* **[Display Groups](display-groups.md)**: Stack lines, define visibility conditions, and render text, items, or blocks above player heads.
* **[Animations](animations.md)**: Create dynamic color-cycling patterns and physical movements for name tag elements.
* **[Billboard Settings](billboards.md)**: Control how display groups orient themselves relative to the viewer's camera.
* **[Placeholder Replacements](placeholders-replacements.md)**: Map and format raw text output from PlaceholderAPI variables.
* **[Show While Looking](show-while-looking.md)**: Only display name tags when a viewer looks directly at the player.
* **[Advanced Configuration](advanced-yml.md)**: Manually configure custom helmet offset adjustments using `advanced.yml`.

To optimize these features for larger servers, refer to the [Performance Tuning Guide](../performance.md).
