# Billboards

> [!IMPORTANT]
> This is the legacy documentation for **UnlimitedNameTags v1.x**. If you are using the modern version 2.x, [click here to view the v2 Wiki](../../README.md).

**UnlimitedNameTags** uses **text display** entities with four **billboard** modes. Each mode controls how the name tag behaves relative to the player.

### Available modes

- **CENTER** (Default)
- **HORIZONTAL**
- **VERTICAL**
- **FIXED**
